## Art and audio
- All pixel art is original to this project: the 16x16 peasant head used for the app icons, and every
  sprite, tile, sky layer and light in `src/render/sprites`, defined in code as palette-indexed strings.
- All sound and music is synthesised at runtime with the Web Audio API (`src/audio`); no samples are used.
- No external asset packs are used. Any added later must be CC0 and recorded here with source and licence.
